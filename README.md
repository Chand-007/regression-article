# Simple Linear Regression Blog Article

This project demonstrates how to build and display a blog article on simple linear regression using ReactJS. It incorporates various sections explaining the concept of linear regression, data preparation, regression analysis, diagnostics, and visualizations.

## Features

- **Main Article Container**: Displays the main content of a blog article with detailed explanations of simple linear regression, using sections like "Preliminaries," "Linear Regression with a Single Explanatory Variable," and more.
  
- **Code Boxes**: Each section contains a code box showcasing Python code snippets for linear regression tasks using libraries like `pandas`, `statsmodels`, `seaborn`, and `matplotlib`.

- **Data Tables**: The app uses static data arrays to populate tables that present datasets like concrete strength data, fly ash data, regression model results, and more.

- **Regression Diagnostics**: Includes various diagnostic plots such as residual histograms, Q-Q plots, and fit plots to assess the quality of the regression model.

- **Navigation**: The page includes both left and right side navigation for easy exploration of the blog content.

## Technologies Used

- **ReactJS**: JavaScript library for building the user interface.
- **CSS**: Styling the components and ensuring responsiveness.
- **MathML**: Used to display mathematical equations.
- **Seaborn, Statsmodels, Pandas**: Libraries referenced in the Python code snippets within the blog content.

## Setup

To run this project locally, follow these steps:

1. Clone the repository:
    git clone https://github.com/your-username/your-repository-name.git

2. Navigate to the project directory:
    cd your-repository-name

3. Install the dependencies:
    npm install

4. Start the development server:
    npm start

5. Open your browser and visit [http://localhost:3000](http://localhost:3000) to view the app.

## File Structure

- **src/**
  - **ArticlePages/**: Contains the components for rendering different sections of the blog article (e.g., `LeftSideNavigation`, `RegressionBlogArticle`, `RightSideNavigation`).
  - **StyleSheets/**: Contains CSS files used for styling different sections of the article.
  - **ArrayTables/**: Contains static JavaScript arrays with sample data for displaying tables in the article.
  
- **public/**
  - The static assets like images and the `index.html` file for the React app.
